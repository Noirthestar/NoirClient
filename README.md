# 🖤 NoirClient

**NoirClient** is an independent Minecraft Java Edition launcher and client project focused on performance, customization, and a better gaming experience.

## ✨ Features

- Custom Minecraft launch engine
- Minecraft version management
- Mod discovery and management
- Microsoft account authentication

## 🚀 Planned Features

- Fabric, Forge, NeoForge, and Quilt support
- CurseForge API integration
- Custom in-game menu and HUD editor
- PvP utilities such as CPS, FPS, and Keystrokes
- Performance optimizations
- Cosmetics including capes, wings, hats, pets, and particles

## 📌 Project Status

NoirClient is currently in active development. Features and compatibility may change.

## 🤝 Mod Authors

We aim to respect mod creators, their licenses, and official distribution requirements.
